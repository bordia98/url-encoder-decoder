Understanding URL Encoding & Percent-Encoding (RFC 3986)

Uniform Resource Identifiers (URIs) and URLs can only be sent over the Internet using the standard ASCII character-set. When URLs contain characters outside of ASCII (such as non-English alphabets, emojis, or spaces) or reserved characters (such as ?, &, =, #, and /) within query parameter values, they must be converted into a valid URI format. This process is called percent-encoding or URL encoding.

How Percent-Encoding Works

In percent-encoding, any reserved or non-ASCII character is replaced by a percent sign (%) followed by the two-digit hexadecimal representation of its byte in UTF-8. For example:

  • A standard space character (ASCII 32) is encoded as %20.
  • The ampersand character & (ASCII 38) is encoded as %26.
  • The equals sign = (ASCII 61) is encoded as %3D.
  • The question mark ? (ASCII 63) is encoded as %3F.

Common Percent-Encoding Characters Reference

Character Description Percent-Encoded Safe to Leave Unencoded?
[Space] Space character %20 or + No (Always encode)
& Ampersand (Query param separator) %26 Only as parameter separator
= Equals (Key-value delimiter) %3D Only as key/value delimiter
? Question mark (Query string starter) %3F Only at start of query string
/ Forward slash (Path separator) %2F Only in URL path, encode in params
# Hash / Fragment identifier %23 Only to mark URL anchor
@ At symbol %40 Encode in query strings
% Percent sign %25 Always encode (unless escape prefix)

Difference: encodeURI vs encodeURIComponent

JavaScript provides two primary built-in functions for URL encoding:

  • encodeURI(url): Designed for encoding a complete URL. It preserves protocol delimiters (://), path separators (/), and query syntax (?, &, =, #). Do not use this when passing user input as a query parameter value, because reserved characters like & will not be escaped and could corrupt the query structure.
  • encodeURIComponent(str): Designed to encode individual components such as query parameter keys and values. It encodes all characters except letters, digits, and -, _, ., !, ~, *, ', (, ).

Frequently Asked Questions (FAQ)

Why does space encode to %20 in some places and + in others?

RFC 3986 specifies %20 as the strict percent-encoded representation of a space character in URIs. However, HTML form submissions (using the MIME type application/x-www-form-urlencoded) traditionally encode spaces as a plus sign (+). Both are commonly supported by backend web servers, but %20 is universally valid everywhere in URLs.

Is my information safe when using this tool?

Yes, absolutely. This entire application runs 100% locally inside your browser via JavaScript. No input data, query parameters, API keys, or URLs are ever transmitted to any remote server or stored in cookies. You can verify this by inspecting the open source code or running it offline.

Can I decode double-encoded URLs?

Yes. If a URL has been accidentally double-encoded (e.g. %2520 instead of %20), simply click the "Decode" button once, swap the result to the input box, and click "Decode" a second time.
